读取范围与独立符号

入口与符号合计最多 6 项。标准与较大的累计元数据访问预算均为 2 万次 / 4 MiB；标准＋元数据容量仅将这两项提高到 10 万次 / 16 MiB，其他标准预算与监控频率不变，需手动选择。累计访问包含监控重复遍历，不是目录项总数。较大档增加其他读取及资源预算；清理目标仍为 5 秒，时间不是硬保证。
